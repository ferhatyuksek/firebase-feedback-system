# 🚀 Firebase Feedback System

Modern tasarımlı, Firebase entegrasyonlu uçtan uca geri bildirim çözümüdür. Hem müşteri girişini hem de yönetici takibini tek bir repo üzerinden yönetir.

## 📂 Proje Yapısı
- **İndex Side:** Müşterilerin geri bildirim bıraktığı ana arayüz.
- **Admin Side:** Gelen verilerin filtrelendiği ve analiz edildiği panel.
